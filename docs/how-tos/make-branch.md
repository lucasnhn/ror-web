# How to - make branch

The sidebar to the right has a "Development" section. Here, you can press "Create a branch".

<img width="298" alt="Pasted image 20250415073203" src="https://github.com/user-attachments/assets/69076b85-5142-466b-aca8-a34bbc382ba7" />

This will open this popup:

<img width="490" alt="Pasted image 20250415073248" src="https://github.com/user-attachments/assets/d987f441-8fed-4c19-a39d-d80f5a26ea45" />

Here, you see that the branch name consists of a number, the issue number, and the issue name. I think this is very practical, cause you can tell someone to go to branch "134", and they can tab to the correct one. However, here I am open to other best practices. By clicking "Create branch", you will get a prompt to pull this branch and switch to it locally, which you will likely want to do.
